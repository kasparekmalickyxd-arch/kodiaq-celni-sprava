CIVKODIAQFL - CELNI SPRAVA OVERLAY

Tato resource NEUPRAVUJE ani nedecryptuje originalni civkodiaqfl YFT.
Pouziva pouze spawn/model civkodiaqfl a pripoji na nej samostatny polep.

Instalace:
1. Ponech puvodni resource s civkodiaqfl tak, jak je. Musi fungovat sama.
2. Nahraj tuto slozku jako novou resource, napr. civkodiaqfl_cs_livery.
3. Do server.cfg dej originalni FL resource prvni a potom:
   ensure civkodiaqfl_cs_livery
4. Spawn puvodniho auta zustava civkodiaqfl.

Prikazy:
/cslivery       - zapnout/vypnout polep
/csliveryreset  - znovu vytvorit overlay

Polep:
- bila zakladni barva vozidla
- modry bok s napisem CELNI SPRAVA
- CUSTOMS / ZOLL / DOUANE
- modra kapota
- zadni modry pas CELNI SPRAVA

Dulezite:
Originalni FL YFT/YTD soubory zustavaji nedotcene. To je zamerne, aby se zachovala
funkcnost puvodniho vozidla a jeho svetel, kol, interieru a fyziky.
